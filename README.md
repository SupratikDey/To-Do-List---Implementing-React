📝 To-Do List Application

This is a basic To Do List application created using React and Vite framework. The application enables the users to create new todo item, mark todo as completed, edit todo item, and delete the todo item. The application comprises of re-usable functional components such as App, Header, TodoList, and TodoItem.

The application implements React State & Props concepts in passing of todo data from one component to another. The todo items are displayed dynamically with the help of map() function and unique keys. Event handling is done to add, edit, complete, and delete todo items.
